# 《充到 80%》后 45 秒（0:30–1:15）方案 v1：纸雕为主，穿插三种 UI 动效

## 一、整体思路

- **主体还是纸雕**：暖光、牛皮纸、有影子，负责"讲故事、打比方"。
- **三种 UI 动效穿插进去**，制造反差。每一种管一类信息，看起来也完全不一样：

| | UI 类型 | 长什么样 | 负责什么 | 借鉴 onetake 的哪招 |
|---|---|---|---|---|
| **UI-1** | 系统界面 | 干净的白色手机设置页，苹果式弹簧动效，手指点开关 | "怎么设置"：实操步骤 | 按钮变窗口（morphRect）、按压回弹（press）、打字 |
| **UI-2** | 热成像 | 同一个纸雕画面被一条扫描线"变成"红外热图（黑→紫→红→橙→黄白），准星锁定、温度数字狂跳 | "看不见的东西"：温度 | infra 片的"每张图都从热开始"、同一构图换一种看法 |
| **UI-3** | 动态排版清单 | 米白底、墨黑大字、橙色勾，一行一行砸下来 | "记住什么"：总结 | 清单打勾（tick）、硬切重击（staccato）、一个点收束全片（one-dot） |

- **反差但不断**：每次从纸雕切到 UI、再从 UI 回到纸雕，都有一个东西"活"过去（承接）。全片还是一镜到底，没有淡入淡出。
- **三处"穿插"有长有短**：UI-1 约 8 秒，UI-2 约 10 秒，UI-3 约 9 秒；中间是纸雕段。

## 二、文案（字幕即文案，按每秒 4–5 字安排停留）

接上半段结尾"所以过了 80%，手机主动减速"：

1. 那整夜插着充电，会不会伤电池？
2. 一直挂在 100%，电池其实也在"硬撑"
3. 所以手机有"优化充电"：先停在 80%
4. 快到你起床，才充满最后 20%
5. 去设置里搜"充电"，把它打开
6. 比充满更伤电池的，是"热"
7. 边充边打游戏，手机能到 40 多度
8. 高温会让电池老得更快
9. 太冷也不行：冬天在室外快充，锂更容易长"刺"
10. （清单）护电池，记住 3 件事：
    - 日常充到 80% 左右就够
    - 别边充边玩大型游戏
    - 不用等到 0% 再充（锂电池没有"记忆效应"）
11. 你的手机，现在充到多少了？（结尾互动，引导评论）

**事实依据**：
- 苹果"优化电池充电"会学习你的作息，先停在 80%，起床前再充满；安卓各家也有类似功能，名字不同，所以文案只说"搜'充电'"。
- 满电长时间挂着高电压、加上发热，会加速老化。
- 高温是锂电池老化的主要因素之一。
- 低温充电更容易析锂，所以手机在很冷时会限制充电。
- 锂电池没有记忆效应，经常放到 0% 反而有害。

**节奏检查**：
- 镜头长度从 0.6 秒到 4.2 秒，差 7 倍，不平均。
- 三次 UI 穿插的入口都是 0.6–0.8 秒的快速转换（爆或击），出来后先停一下。
- 完全静止的停顿：时间条停在 80% 那一段、43.6° 锁定、清单最后一条、结尾。
- 每个换场都有承接物：屏幕 → 开关圆钮 → 太阳 → 画面 → 准星 → 点 → 线 → 便签。

## 四、三种 UI 的视觉规范（和纸雕形成反差）

| | 纸雕 | UI-1 系统界面 | UI-2 热成像 | UI-3 清单 |
|---|---|---|---|---|
| 底色 | 牛皮纸、暖光 | 纯白 / 浅灰 #F4F4F6 | 黑 → 热色板 | 米白 #EFE9DF + 点阵 |
| 字体 | 宋体字幕纸条 | 黑体，细、干净 | 等宽数字 + 黑体 | 宋体粗大字 + 斜体英文点缀 |
| 强调色 | 朱红 | 系统绿（开关）+ 橙（80%） | 白黄高光 / 冰蓝 | 橙色勾 |
| 运动 | 立体书翻起、吊牌落下 | 苹果式弹簧（不弹太多） | 扫描线、准星吸附、数字狂跳 | 遮罩上升、砸下、勾弹出 |
| 质感 | 纸纹、颗粒、阴影 | 无颗粒、无阴影，极度干净 | 噪点 + 扫描线 | 极淡纸纹 |

## 五、声音

- 纸雕段：纸张声、台钟滴答、闹钟、轻节拍。
- UI-1：玻璃般清脆的点击、开关"咔嗒"、时间条划过的风声。
- UI-2：扫描的电流嗡声、准星锁定"嘀"、温度狂跳的计数声；变冷时一声冰裂。
- UI-3：每一行砸下是一记低频加木头声，勾是玻璃音；最后回到纸雕时是纸片飘落声。
- 同样导出"有铺底版"和"仅音效版"。

## 六、制作计划

1. 你确认这份方案（文案、三种 UI、节奏）。

4. 和前 30 秒拼成完整的 1 分 15 秒，一起交付有铺底版和仅音效版。
