# 《充到 80%，为什么突然变慢了？》30 秒开头样片：文案与节奏

- 风格：纸雕微缩剧场（真实纸纹、聚光、硬影）+ UI 动效（手机界面、曲线、电量表、贴纸）+ 一镜到底
- 没有配音，字幕就是文案；中文按每秒 4–5 个字安排停留时间
- 事实依据：锂电池充电分两段，先恒流快充，到约 70–80% 后转恒压、电流越来越小；接近满电时还大电流硬充，锂会在负极表面析出、长成枝晶，导致老化、鼓包，严重时刺穿隔膜短路

## 选题自检（按「一句话反常识问题」）

- 每天碰到的现象：充电到 80% 变慢 ✔
- 一句话问出反常识：「充到 80%，为什么突然变慢了？」✔
- 因果链短：快满了 → 车位难找 → 硬塞会长刺 → 所以减速 ✔（四步讲完）

## 承接链（全片不切镜头）

开头的 **80% 大数字**跳出手机屏幕，落成曲线上的那个点 → 镜头回到手机，**推进屏幕** → 屏幕变成电池图标，电池里的**深蓝色涨满全屏** → 同一个颜色里就是电池内部 → 右上角的**电量表**接着讲完。

## 后半段可以接什么（做整条时）

1. 所以，一直插着充电会伤电池吗？（手机的"优化充电"会停在 80%）
2. 冬天在室外快充更伤：低温时锂更容易析出
3. 一句话总结：日常充到 80% 左右拔掉，最护电池
