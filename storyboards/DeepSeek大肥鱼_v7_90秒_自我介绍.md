# 大肥鱼 · 自我介绍（v7，90 秒）

叙事完全按参考片（Overlay Studio 操作流程介绍）的方法来：

- **一段对话串起全片。** 平板上的 DeepSeek 对话框是"大本营"。每一章都从主人打一条新消息开始，打字和发送的过程都要演出来。大肥鱼回一句，然后跳出屏幕去演示。
- **开场。** 她是聊天里的一张平面小贴纸 → 被揭起来，立成纸片 → 转一圈变成立体的 → 蹬一下跳出屏幕，屏幕荡开一圈波纹。
- **章节。** 先打出大号步骤名"第 N 步 · xxx"，停一下，再缩到左上角当进度条；底部有章节导航条。
- **界面真的在动。** 她跳到哪个界面上，那个界面就把这件事演一遍。
- **转场不硬切。** 她扎进屏幕 → 屏幕上开一个洞 → 镜头钻进去，到另一个世界。
- **动作有花样也有重量。** 起跳先下蹲，落地压扁再弹回；每个动作都要让人看懂她在干嘛。

128 BPM，1 小节 = 4 拍 = 1.875 秒，全片 48 小节。底部导航条：`我是谁 · 我火过 · 我在 B站 · 我每天 · 这条片子怎么做的`。
