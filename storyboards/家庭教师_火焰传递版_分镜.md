# 《家庭教师》彭格列羁绊 · 火焰传递版分镜（草案 v1）

- 时长：约 90 秒，竖屏 1080×1920
- 风格：暗场纸雕剧场（真实纸纹、聚光、硬影、暗角、颗粒）+ 角色自己的死气之炎
- 核心：**一团火在角色之间传递，镜头不切**。火从纲吉出发，依次点亮每位守护者，最后全部回到纲吉身边。火焰的传递本身就是"羁绊"。
- 舞台：一条横向长纸雕舞台，七个小场景从左到右排开（并盛中学 → 后巷 → 天台 → 拳击部 → 纲吉家 → 屋顶 → 黑曜乐园），镜头沿着舞台走，场景之间用"火星飞过去"承接。

> 时间先按 90 秒估。歌给我之后，按歌词和鼓点重新对齐，每个"爆"和"击"都落在鼓点上。

## 节奏类型

- **停**：画面几乎静止，至少 1 秒，让情绪落下来
- **常**：正常叙事
- **爆**：1.5 秒内连续 3 个以上大变化
- **击**：0.3 秒左右一下的重击、硬砸

## 节奏检查

- 镜头长度从 2 秒到 9 秒，差 4.5 倍，不平均。
- 停顿：开场、天台、云雀、全暗时刻、结尾。约三成时长是安静的。
- 爆发：点燃（0:06）、炸药三连（0:25）、了平的拳头（0:40）、火环汇聚（1:13）。
- 重击：子弹、刀光切画面、蓝波闪白、金光。
- 每个换场都有承接物（表里的第 6 列），全片没有一个淡入淡出。

## 角色和羁绊的表达

| 角色 | 和纲吉的羁绊怎么拍 |

| Reborn | 子弹点燃一切，然后坐在纲吉肩上：老师、起点 |

| 云雀 | 不回头、不靠近，但火焰在：孤高的守护 |
| 骸 / 库洛姆 | 一张纸的两面：亦敌亦友 |

## 需要你准备的角色图

全身、透明背景、无阴影、同一画风，**火焰不用画**（火是代码做的，才会发光、会动）。

| 角色 | 姿势 |
|---|---|
| 泽田纲吉 | 1 低头沮丧（废柴） 2 抬头握拳（点火） 3 背影站立（结尾） |
| Reborn | 1 坐姿（放在纲吉肩上） 2 举枪 |
| 狱寺隼人 | 1 单膝跪地 2 扬手扔炸药 |
| 山本武 | 1 背影回头笑 2 持刀 |
| 笹川了平 | 1 出拳正面（拳头朝镜头） |
| 蓝波 | 1 哭着趴在地上 |
| 云雀恭弥 | 1 背影站立，手持浮萍拐 |
| 六道骸 | 1 正面站立 |
| 库洛姆 | 1 正面站立（和骸同一个姿势、同样大小，做一张纸的两面） |

另外每人一张**结尾背影**最好。没有的话，结尾用剪影代替。
