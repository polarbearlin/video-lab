## 三、对我们最有用的五件事

1. **常驻 HUD（华邮）**：社会事件片全程挂一个“时间戳 + 小地图 / 进度条”，切到哪段素材都知道几点、在哪、事件进展到哪。纯代码，成本最低，收益最大。
2. **一张会长大的主画布（回形针、衣戈）**：每期设计一张贯穿全片的图——事件时间轴 / 人物关系链 / 现场平面图——从空白开始，旁白讲到哪长到哪，反复回到它。
3. **标注语法统一**：框人用一种框、解释用一种卡、术语用一种括号、原始记录用一种文字卡，全片不换。
4. **当事人保护用设计解决（衣戈）**：照片卡里的普通当事人一律剪影或打码，关系图里用“杨某、张某”，图标代替人脸。
5. **克制的调性**：动效速度慢一点、少回弹，颜色少（底色 + 一个强调色），音乐让位于事实。

## 四、社会焦点风格包 v0（建议）

| 项 | 建议 |
|---|---|
| 主画布 | 事件时间轴（横向长卷，节点 = 时间 + 一张证据卡）+ 现场平面图 / 卫星图（标点、箭头、区域） |
| HUD | 左上时间戳（如“6 月 1 日 18:07”），右上小地图定位点，底部事件进度条 |
| 证据卡 | 照片卡（米白边框、可剪影化）、文书卡（荧光圈重点）、原始记录卡（白底等宽字） |
| 人物 | 关系链节点（姓氏 + 某、身份标签），普通当事人不画脸；公众人物可用照片卡 |
| 插画 | 少用；只用于不能拍的场景示意（剪影、物件、空间），标“示意”，不还原暴力 |
| 配色 | 米白 / 浅灰底 + 墨黑 + 一个强调色（警示橙），不用大面积红 |
| 字体 | 标题宋体（思源宋体）+ 正文黑体 + 记录类等宽字 |
| 动效 | 元素生长、连线描出、框选、平移镜头；回弹很小，节奏均匀 |
| 声音 | 低频垫底、少旋律；关键节点用很轻的“落点”，不要冲击音效 |
