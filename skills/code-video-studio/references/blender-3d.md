# Blender 3D 渲染流程（产品 / 角色 / 质感镜头）

来源：Clawd Motion Lab 的两份提示词包（"No After Effects"、"Neon Jump"，都是 Opus 5.5 + Blender 5 + Cycles GPU）、onetake 的 domino / clawd 案例，以及《充到 80%》3D 段的实践。

## 什么时候用 Blender，什么时候用 three.js

| | three.js（网页逐帧） | Blender Cycles |
|---|---|---|
| 质感 | 好：PBR、环境反射、后期景深 | 最好：真实光线追踪、玻璃折射、焦散、真景深、真运动模糊 |
| 速度 | 无显卡云端约 2 秒/帧；有显卡零点几秒 | **必须有显卡**：RTX 4070 约 1.5–7 秒/帧；CPU 2.5–3.5 分钟/帧（不可用） |
| UI / 文字 | 原生：DOM、Canvas 直接画 | 先用网页渲染成贴图 / 图片序列，再贴进 3D |
| 适合 | 纸雕、UI 动效、科普图解、快速迭代 | 产品特写、角色片、玻璃金属、霓虹夜景、品牌片 |

云端（无显卡）只能写脚本 + 小尺寸低采样试渲；正式渲染交给用户本地显卡（见 `production.md` 的本地联动）。

## 文件结构（一个片子一个文件夹）

```
timeline.py   唯一的时间表：节拍、事件、镜头关键点、物体位姿；画面、UI、声音都读它
build_ui.*    网页界面 → 截图成贴图（3x 分辨率），或逐帧图片序列（屏幕内容）
scene.py      从零建 Blender 场景：blender -b --factory-startup -P scene.py -- [参数]
gpu.py        把 Cycles 切到 OptiX / CUDA / Metal（GPU 选项是用户偏好，不存在 .blend 里，每次渲染都要传）
compose.py    ffmpeg 后期：调色滤镜（热成像等）、叠加网页字幕层、混音
score.py      声音：读 timeline.py，事件落在同一帧
```

原则：**场景是脚本，不是手工文件**。每次改动都从头重建 .blend，所以任何修改都能复现。

## 提示词结构（直接复用）

```
BRAND   要替换的一块：HERO（主角外形、色号）、APP / SET / PROP / SIGNS / PALETTE
FORMAT  Blender 5 Python, Cycles GPU, 分辨率, fps, 时长, BPM；一个 timeline.py 驱动画面和声音
BEATS   按秒写：每个节拍发生什么；每一跳都要改变点什么，不改变任何东西的动作删掉
CAMERA  一句话：起幅 → 跟随方式 → 甩到哪里 → 落幅（循环片：落幅 = 起幅）
LOOK    材质和光的关键一句（比如"UI 是黑色光面玻璃下的自发光，灯不要出现在 UI 的反射里"）、bloom、0.5 快门模糊、AgX
CHECKS  先出贴图 / 半分辨率 9–18 张节拍截图拼总览，确认后再全分辨率渲染
```

## 视觉要点（都是被返工过才学到的）

- **灯不要照进光面 UI 的反射里**：大面积补光在光面屏幕、玻璃面板上会变成一大块白。把轮廓光、顶光对光泽射线隐藏（`visible_glossy = False`），UI 高光降到 0.1、粗糙度 0.32。
- **主角颜色要"读得出来"**：曝光和底色一起调（例：曝光 0.6 → 0.15，底色压暗），否则赤陶色会被渲成浅鲑鱼色。
- **给主角一盏跟着走的小补光**：霓虹只负责反射，脸 / 产品正面靠这盏灯。
- **景深**：主角浅景深；对焦距离每帧算到主角身上；清单类镜头可以逐张"对焦转移"。
- **字要读得清**：关键字在屏幕上 ≥ 24 px 高、压扁比 ≥ 0.6；镜头要在这个节拍里给到读字的角度。
- **慢动作改距离，不改重力**：抛物线形状不变，只把时间轴放慢（6% 速度）。
- **循环**：世界做成可重复的一段（instance 几次），第 N+1 帧 = 第 1 帧；用帧差检查接缝不比相邻帧跳得大。
- **颗粒**：逐帧颗粒会让码率暴涨（118 MB → 29 MB），终版去掉颗粒，保留暗角，CRF 17–18。
- **模型**：网上 CC-BY 模型可用（注意署名、去 logo）；需要精确时让 Blender Agent 按 `assets` 里的建模提示词建（屏幕单独网格、UV 铺满 0–1、材质按名分槽）。

## 渲染步骤

1. `blender -b --factory-startup -P scene.py -- --preview` → 半分辨率、40–48 采样、9–18 张节拍截图 → 拼总览给用户。
2. 用户确认后：`blender -b -P scene.py -- --render -P gpu.py`，128 采样自适应 + OptiX 降噪 + 持续数据（persistent data），0.5 快门。
3. 先计时一帧再开全片（CPU 和 GPU 差几十倍，误用 CPU 是最常见的坑）。
4. 只重渲出问题的帧段（`--frames 105-145`）。
5. ffmpeg 编码 H.264 High CRF 17–18、`+faststart`，混入 AAC 320k。

## 声音

和画面同一个 timeline.py；纯 numpy / scipy / pedalboard 合成；看频谱图检查低频是否糊成一堵墙（引擎和 808 打架时，引擎降一半、70 Hz 高通、慢动作时压低）；循环片渲 3 遍取中间一遍，尾巴绕回开头。平台发布约 -14 LUFS。
