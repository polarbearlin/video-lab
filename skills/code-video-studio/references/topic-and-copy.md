# 选题、文案与节奏：知识科普短视频

来源：用户实测反馈 + 视频号「许先森Ai」的复盘（8 条科普视频，最高 215 万、最低 8000 播放），以及《充到 80% 为什么变慢》样片（`assets/example-charge.*`，用户评价"挺有辨识度"）。**文案和节奏是重中之重，表现形式其次。**

## 1. 选题自检（开做前逐条过）

| 检查 | 通过的例子 | 不通过的例子 |
|---|---|---|
| 是不是每天都碰到的现象？ | 充电到 80% 变慢、闻到燃气臭味、二维码会不会用完 | 金融危机、通货膨胀 |
| 能不能用**一句话问出一个反常识的问题**？ | "上海发一张照片，洛杉矶 0.07 秒就收到了，它是怎么过去的？" | "聊聊锂电池的工作原理" |
| 因果链够不够短？4 步以内讲完 | 快满了 → 车位难找 → 硬塞长刺 → 所以减速 | 因果链长、要很多背景知识 |
| 原理能不能"画出来"？ | 离子、电波、分子、电流、结构 | 纯概念、纯观点 |

适合：生活科普、心理学、诺贝尔奖类原理。数据一般：金融、历史。用户给题材时，先用这张表帮他筛，给出 3–5 个改写成"一句话问题"的选题。

## 2. 开头 3 秒

- **第一帧就是完整画面**：不要黑场慢慢亮，不要片头。观众的手指一直放在屏幕上。
- 第一句字幕直接甩出反常识的问题（大标题，第一帧就完整显示）。
- 第 1 秒之内要有一个"动作"把问题具体化（如：快充 65W 被"慢充 10W"砸下来）。

## 3. 字幕和画面必须同步

- 观众是在**看**知识，不是在**读**知识：字幕一换，画面必须跟着动。字幕变了、画面超过 2 秒不动，观众会走，也会觉得粗糙。
- 字幕停留按阅读速度算：中文每秒 4–5 个字。12 个字至少停 2.5–3 秒；超过 13 个字在逗号处折两行。
- 关键词标红（文案里用【】标出），每句最多一处。
- 数字和事实必须准确；有出入的说法加"可能""很多"（如"很多快充半小时到 80%"）。

## 4. 让节奏本身讲道理

最有辨识度的一招：**画面的速度 = 内容的速度**。
- 讲"快"的部分，画面一口气完成（快充曲线 0.8 秒画完、离子一口气冲进去）；
- 讲"慢"的部分，画面就真的慢（慢充曲线用 2.8 秒慢慢爬、离子左右找车位）；
- 讲"危险"用重击（三根刺、短路章、白闪、镜头震）；
- 揭晓答案前放一段完全静止（"手机坏了？不，它是故意的"停 1 秒）。

节奏标注：击 / 爆 / 常 / 慢 / 停，写进节奏表（见 `one-take.md`）。

## 5. 比喻要能做成纸雕场景

把抽象原理换成生活里的空间：锂离子停进负极 = 停车场找车位；数据包过海 = 快递分拣；神经递质 = 码头装卸。比喻场景用纸雕搭出来，UI 元素（数字、曲线、电量表、贴纸）当纸片立在场景里，或者作为叠层。

## 6. 文案格式（交给用户确认的样子）

先交"文案与节奏表"（Markdown），用户确认后再做画面：

```
| 时间 | 时长 | 字幕 | 画面 | 节奏 |
| 0.0–3.0 | 3.0s | 充到 80%，为什么突然变慢了？ | 手机特写 79%→80%，1.0s "慢充 10W"砸下 | 击 |
```

另写：选题自检结果、承接链、事实依据、后半段可以接什么。

## 7. 先做开头样片

先做 15–30 秒开头样片，用户满意再做整条（45–60 秒）。整条不满意时返工太贵，渲染也慢。

## 8. 配乐和配音

- 科普类发布时用**仅音效版**，在抖音 / 视频号曲库里挑热门歌：有版权，还能蹭流量。不要把热门歌直接合成进视频再上传（版权识别可能静音或限流）。
- 样片里用代码合成的轻节拍铺底，只用来看节奏；同时导出"有铺底版"和"仅音效版"。
- 默认没有配音，字幕即文案。用户要配音时，用合成语音按配音时长重新卡点。

## 9. 心态

同一套方法，每条之间的播放量能差 200 倍。不爆是常态，爆了是惊喜；靠稳定产出和选题命中率，不靠单条。
