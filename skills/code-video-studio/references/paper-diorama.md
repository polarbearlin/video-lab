# 纸雕微缩剧场：制作流程

完整可运行示例：`assets/example-paper-diorama.js`（《老板画饼》0:00–2:05，新形象版）。新片子以它为骨架，改场景、时间表和素材。

## 1. 视觉配方

- **材质**：地板用 ambientCG `Cardboard002`（瓦楞纸板），墙用 `Paper004`（牛皮纸），白纸道具用 `Paper001`。每种都加载 Color + NormalGL + Roughness 三张贴图，纸纤维的凹凸是质感的关键。
- **光**：一盏暖色聚光灯（`#ffd6a0`，decay 0，强度约 3.2）从左上前方打，开阴影；冷色平行光做轮廓光（`#a9c1ff`，0.45）；半球光做环境光（0.55）。前副歌这类情绪段把主光压到 40%，打开一盏台灯点光源。
- **阴影**：`PCFSoftShadowMap`，阴影贴图 1536。VSM 带模糊更柔，但在软件渲染下很慢。
- **色调**：`ACESFilmicToneMapping`，曝光 1.05；雾色和背景色都是深棕 `#2a1d12`。
- **后期叠层（DOM）**：暗角径向渐变，35mm 胶片颗粒 `mix-blend-mode: overlay`，开头和结尾淡入淡出。
- **字幕**：米色纸条（`#F6F0E2`，旋转 -1°，左侧红条），宋体 700，逐字浮现。左上角黑底黄字栏目角标。

## 2. 场景结构

把整首歌拆成几个"区"，沿 x 轴排成一条长舞台，镜头横移过去，比硬切更连贯：

| 区 | x 位置 | 用于 |
|---|---|---|
| 城市 / 公告墙 | -170 | 主歌（进城、贴新规） |
| 办公室 | -100 | 对白、拍肩、签字 |
| 书桌（台灯） | -45 | 前副歌、内心戏 |
| 墙上画饼 | 0 | 副歌高光 |
| 房子 | 50 | "买不走我的家" |
| 合同 / 卡片 | 0, z 30–60 | 地上的道具、俯拍 |

单位约 1 = 1cm；人物立牌高 40–46。地板 480 宽，背墙在 z=-50，两侧有墙。

## 3. 核心工具函数

- `standee(tex, heightCm, {pos, ry, center})`：一张能立起来的纸片。PlaneGeometry 底边对齐原点，`alphaTest .5` + `customDepthMaterial`，让阴影跟着图片轮廓走。外层套一个 `hinge` Group 做铰链。
- `pop(s, t, up, down, d)`：立体书式翻起，从平躺（-90°）弹到直立，用回弹缓动 eBack；到 down 时再倒下去。**这是这个风格的签名动作。**
- `popScale(s, t, up, down)`：缩放弹出，用于对话气泡、问号、印章。
- `drop(s, t, up, y, down)`：吊牌从上方落下并轻微摆动，带吊绳（细圆柱）。
- `hangTex / bubbleTex / canvasTex`：用 Canvas2D 画吊牌、剪纸对话气泡（白底黑框加尾巴）、日历、通知、账本等，做成 CanvasTexture。
- `svgTex(svg, viewBox)`：把 SVG 字符串画成纹理（代码画的人物）。注意 SVG 当图片用时读不到网页字体，文字要用 Canvas 画。
- `cutout(svg)`：先画一圈粗白描边再画本体，得到剪纸白边。
- 动态画布（每帧重画并 `needsUpdate`）：红笔在墙上画圈的进度、合同高亮、手机缴费记录逐行出现。

## 4. 镜头与灯光

- 透视相机 fov 50（竖屏下 fov 32 太窄，只拍到局部）。
- 机位字典 `P = {名字: [位置, 看向]}`，时间线 `SHOTS = [[开始秒, 机位名], ...]`。
- 每个镜头前 0.75 秒和上一个镜头 eIO 插值过渡，停留期间缓慢推近 7%。
- 主光跟着镜头走：`key.position.x = lookX - 75`，像跟随的舞台灯。
- 竖屏取景：人物 40cm 高时，相机距离约 70–90 拍半身，130–180 拍全景。

## 5. 时间轴组织

- 所有动作时间取自逐字歌词时间表：`ch(行号, 字号)` 返回某个字被唱到的秒数。例如"大"字落下时饼猛地变大：`eBack(prog(t, ch(10,6)-.05, ch(10,6)+.5))`。
- **重复段落用时间平移复用**：第二轮"前副歌 + 两遍副歌"= 第一轮整体平移 53.05 秒，直接 `animate(t - SHIFT)`，镜头限制在第一轮的镜头表里，并禁止在平移起点做镜头混合。
- 新段落（比如主歌二）写独立函数。进入前先把所有物件隐藏，再只打开需要的，避免上一帧的状态残留（多进程渲染时每个进程看到的帧顺序不同，残留会导致不确定的画面）。
- 每帧开头把所有物件复位为可见，再交给 animate 逐个设定；只在某些段落出现的物件，每帧先隐藏。

## 6. 换成用户自己的角色

用户用图片模型出的角色图通常是**带透明通道的 PNG/WebP**，先检查 alpha，直接用原图 alpha 最干净；只有纯白底没有 alpha 时才用 rembg 抠图。用 `scripts/cutout_character.py`：保留最大连通区域（去掉边上误入的行李箱、拖鞋碎片），加 ~14px 米白剪纸边，需要时左右镜像（让伸手方向朝向对方）。

在场景里，**不改动画逻辑，只换贴图**：给每个旧立牌建一个新立牌，每帧把旧立牌的可见性、位置、旋转、缩放复制给新立牌，再隐藏旧的（`applySwap`）。同一个旧立牌可以按时间映射到不同的新图（比如老板前面招手、后面插兜站着）。道具位置跟着新角色的手调整（例如递饼时饼的位置）。人物高度按新图比例微调，近景别切掉头。

## 7. 渲染与性能

- 无显卡环境 Chrome 参数：`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`。约 2 秒/帧（3 进程），12 秒一段约 13 分钟。
- 分段渲染脚本见 `scripts/render_segments.sh`，段与段之间浏览器完全重启。
- 拼接：ffmpeg concat 复制流，再一次编码加音频。
- 只改了某一段时只重渲那段；结尾淡出可以在 ffmpeg 里加（`fade=t=out`），不用重渲。

## 8. 踩过的坑

- 页面 html 复制改名后，记得把里面引用的 js 也改过来（曾经渲染出旧人物白跑一轮）。
- 某个字体文件下载损坏会让 `document.fonts.load` 报 NetworkError、页面永远不 ready：用 fontTools 检查字体，或者子集化后再用。
- ZCOOL XiaoWei 的"回"字渲染成实心方块；字幕优先用霞鹜文楷（LXGW WenKai）子集。
- CylinderGeometry 顶面贴图会旋转 90°：`tex.center.set(.5,.5); tex.rotation = Math.PI/2`。
- 第一个镜头的横幅会挡住后面镜头里的饼：每个吊牌都要给收起时间。
- 场景一多，"只在某段出现"的物件一定要显式隐藏，否则会跑进别的镜头。
