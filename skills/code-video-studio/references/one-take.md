# 一镜到底与节奏：让片子不像 PPT

方法借鉴自 onetake（github.com/feitangyuan/onetake，PolyForm 非商业许可：**只借鉴思路，不复制它的代码**）。我们的实现见 `assets/example-onetake-ui.js`、`assets/example-onetake-score.py`。

## 1. 承接：每个换场都要"有东西活下来"

AI 做的视频最常见的毛病是"像 PPT"：画面 A 结束，淡出，画面 B 出来，彼此没关系。规则：**每个节拍的边界，上一个画面里必须有一个东西留下来，并且看得见地变成下一个画面**。

常用承接手法：

| 手法 | 例子 |
|---|---|
| 长出来 | 光标长成输入框；一个小卡片长成手机；火星落地长成火焰 |
| 收成一条线 / 一个点 | 输入框收成一条线，线射出去变成时间轴；整个画面收回成一个点，点落在字标上当句号 |
| 推进去 | 镜头推进卡片/屏幕，直到它就是下一个场景 |
| 跟着走 | 镜头跟着一个运动的东西（火星、纸飞机、小鸟）甩到下一个地方 |
| 切开 / 擦开 | 刀光把画面切开，下半就是下一场；烟散开就是下一场 |
| 颜色接力 | 一种颜色铺满全屏，退去时露出下一场 |

镜头**不切**：同一台镜头跟着主体走，甩向下一个落点，手持轻微晃动，撞击时震一下，停顿时完全静止。

## 2. 分镜表必须有"承接"一列

做分镜时每一行写：时间、时长、画面、**承接物（谁活到下一拍）**、节奏类型（停 / 常 / 爆 / 击）。承接物一栏写不出来，就说明这里会像 PPT，回去改。

## 3. 节奏要有形状

- 镜头长度不能平均：最长和最短至少差 4 倍（变异系数 ≥ 0.25）。"每个角色 6 秒轮流登场"就是反面例子。
- 至少 25% 的画面是静止的，至少有一段 ≥ 1 秒的完全停顿：停顿让动作有力量。
- 至少一次"爆发"：1.5 秒内 ≥ 3 个大变化，不要等间隔出现。
- 高潮用"重击"：每个 0.25–0.4 秒的硬切大字或画面。
- 连续两个镜头不要用同样的方式结束（弹出、模糊滑走、硬切轮换着用）。
- 去掉和主题无关的装饰（无意义的彩纸屑、闪光）。

## 4. 运动模糊

快速移动的东西每帧拍几张取平均，会拖出模糊，不会一顿一顿。渲染时加：

```
node harness/render.mjs <demo> --mb 6 --shutter 0.5
```

代价：每帧截图 6 次，2D 页面 15 秒约 10–15 分钟（3 进程）；Three.js 页面太慢，只在快速段落用，或者只在终版用。

## 5. 声音放进同一个房间

- 合成拟音要有材质：玻璃（基频 + 非谐波泛音 + 噪声瞬态）、木头（低频敲击 + 3 kHz 脆响）、空气（滑动带通噪声 = whoosh）、低频重击（带音高下滑的正弦 + 饱和）、气泡（上滑共振）。纯正弦听起来像 8-bit 游戏。
- 所有声音送进**同一份混响**（合成脉冲响应，约 1.1 秒），远的东西送得多（0.5），近的少（0.15）。这是让零散音效变成"一部片"的关键。
- 不要一个事件一个声音：打字只给部分按键声，随机力度。
- 动态跟画面走：停顿时安静，重击是全片最响。拟音峰值约 -8 dBFS，成片约 -16 LUFS（纯音效片）或对齐原曲（MV）。

## 6. 先拆参考片的数字

用户发来喜欢的参考视频时，先量：静止画面占比、平均多久切一次、最长和最短镜头、爆发出现在哪里、运动的快慢曲线。照着数字做，而不是凭感觉"差不多"。

```
ffmpeg -i ref.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time   # 切点
```

## 7. 适用范围

- UI 动效、产品介绍、知识科普：一镜到底最合适，整片一条承接链。
- 剧情 MV（如纸雕剧场）：一条长舞台 + 一台镜头沿着它走（`paper-diorama.md` 的做法），段落之间用"跟着走 / 推进去 / 颜色接力"承接。
- 角色群像（如七色火焰）：用一个贯穿全片的物件（火焰、信物）在角色之间传递，承接本身就是"羁绊"。
