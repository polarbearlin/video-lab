# 第 6 步：剪辑与渲染（Python + Pillow + ffmpeg）

渲染在云端容器里做，不需要用户的电脑。代码模板在 `assets/pipeline/`，真实项目样例是 `assets/pipeline/example_full.py`（《黄仁勋复职的十一天》的完整时间线，452 行，照它的结构写新项目）。

## 准备

```sh
bash scripts/setup_fonts.sh                     # 思源黑体 Medium/Bold/Black → 仓库根/assets/fonts（.gitignore 里，每个新会话跑一次）
cp <skill>/assets/pipeline/{frame,render,fx,score}.py demos/<项目>/film/
cp <skill>/assets/pipeline/example_full.py demos/<项目>/film/full.py   # 再按新文案改
export VL_OUT=/home/user/<项目>_film             # 成片输出目录（mp4 不进仓库）
```
依赖：ffmpeg（带 rubberband、libass）、Pillow、numpy、librosa、pyloudnorm、faster-whisper。缺什么 pip 装什么。

## 版式（对标参考视频）

竖屏 1080×1920（视频号 / 抖音主版本）：
- 顶部：小标签“频道名 · 热点拆解”（y≈330）+ 绿色短条，两行固定标题：第一行绿色 Black 82 号（≤ 10 字，如“黄仁勋 11 天被请回”），第二行白色 Black 58 号（问句，如“一通电话，董事会为何全票反转？”）。
- 中间 16:9 画面窗：y 600–1208（1080×608），全片所有镜头都在窗里。
- 窗下字幕：MarginV 1238，50 px，顶对齐。
- 底部频道条（y≈1352）：绿色竖条 + 频道名 + 右侧口号；再往下一行超大淡色频道名做底纹。
- 横屏 1920×1080：同一条画面窗时间线放满屏，字幕 58 px 压底部。默认只出竖屏，用户要再出横屏。

改 `frame.py` 顶部的常量：`BRAND`、`TAG`、`TITLE1`、`TITLE2`、主色。主色按题材定（英伟达题材用 #76B900 绿 + 暗红），红色只用于质疑、风险、调查。

## 镜头节奏

参考视频实测：平均 4 秒一切、中位数 2.2 秒；开头 75 秒切 29 次。5 分钟片做 80–100 个镜头，钩子段 1.5–2 秒一切。

画面四层：真实视频约 45%、文件截图拼贴约 30%、数据图约 10%、示意插画约 15%。

## 镜头类型（`render.py` / `fx.py`）

| 类型 | 函数 | 要点 |
|---|---|---|
| 新闻 / 真实视频 | `R.seg_clip`、`fx.seg_clip_l` | 慢推 1.0→1.06、轻调色、暗角；不够长自动定格补齐；`seg_clip_l` 可加顶部标签、日期章、引语、来源角标。画面是铺满后裁切：竖拍素材只留中间一条，主体在中间就够用；要保留整幅竖拍，另写 split + boxblur + overlay 的模糊填充滤镜 |
| 截图拼贴卡 | `R.seg_card` | 撕纸边、滑入 + 慢推；大号中文引语（Black 96 + 绿色下划线）；日期章（Black 84）；高亮是**文字下方的绿色下划线**；来源角标 |
| 示意插画 | `R.seg_still`、`fx.seg_still_t` | Ken Burns 慢推，角落“示意图” |
| 涨跌柱 | `R.seg_bars` | 中国配色：红涨绿跌；主角那天标 `+31.5%` 这种带符号的数；负数标签放柱子下方居中，不出画 |
| 对比折线 | `fx.seg_lines` | 两条线按起点归一（如个股 vs 纳指），85% 时长画完 |
| 计数器 | `fx.seg_counter` | 数字滚动，65% 时长到位 |
| 标题卡 / 日期快闪 | `R.seg_title` | 冷开场后的“11/12 辞职 / 11/17 被拒 / 11/23 复职” |
| 片尾 | `fx.seg_end` | 素材和配乐署名（分行，别溢出）+ 评论区提问（“这十一天，你觉得谁赢了？评论区聊聊。”） |

## 时间线（`full.py` 的结构）

1. **冷开场 3–5 秒**：英文新闻主播原声 + 五六个快切 → 日期快闪 1.2 秒 → 第 1 份旁白。
2. **逐句排镜头**：`SHOTS[(份, 行)] = [(权重, 镜头), …]`，一句旁白配 1–3 个镜头，按权重分这句的时长；`EXT` 表示沿用上一句最后一个镜头。每句起止来自 `lines_aligned.json`，再用 `silences()` 把句子边界吸到真实停顿上。
3. **插原声**：在两句之间静音的**中点**把旁白剪开、插入原声（不能剪在字上）；原声画面出中英字幕。
4. **片尾 4 秒**。
5. 每个镜头渲成 1920×1080/30fps 的小段（带 `.dur` 缓存，改一个镜头只重渲这一个），`R.concat` 拼接，`build_audio` 混音，`R.package(..., which=('v',))` 套外框和字幕出竖屏。

## 字幕

- 以**实际配音**为准（用户念得和稿子不一样时跟配音），字幕里数字换回阿拉伯数字（`十一月八日` → `11月8日`）、英文名换回原文。
- 每条 ≤ 18 字，按标点切；原声段中英双行，翻译要准（“I spoke to them … I convinced them” → “我跟他们谈了……我说服了他们”，单复数别弄错）。
- 字幕不能和原声字幕、标签重叠：标签一律放画面顶部（`label_png` 的 ly=80），不挡新闻台下方的字条。

## 卡片可读性（审片最常挑的）

- 整页截图缩到窗口里字太小：必须加一行大号中文引语说重点，或者用裁切图。
- 截图偏暗看不清（如 PBS 暗色页面）：换成视频镜头，别硬用。
- 高亮用下划线，不要整块色条盖住字。
- 柱状图的数字标签：带正负号、颜色和涨跌一致、不出画。

## 渲染时间与交付

用 `render_parallel.py 4` 并行渲染：5 分钟片 100 个镜头约 10 分钟（4 核），之后只重渲改动的镜头。注意缓存只认时长，改了内容没改时长的镜头要删缓存（见 `assets/pipeline/README.md`）。渲染放后台跑，跑完用 SendUserFile 把竖屏 mp4 发给用户（用户原话：“渲染好了就发我”）。用户问“是谁渲染”：在云端容器里由你渲染，用户电脑不用开着。
