# 第 3 步：豆包配音脚本（用户用克隆音色录）

用户把脚本**一份一份**粘贴进豆包的克隆声音对话，导出音频发回来。不花即梦积分，是默认做法（即梦全能配音只在用户明确要求时用，要先报价）。
完整样例：`assets/example/黄仁勋_豆包配音脚本.md`（3 份）。

## 规则

- **只在拿到定稿（Gemini 优化后用户发回的版本）后出**。
- 一个文件装全部份：`<片名>_豆包配音脚本_v1.md`，SendUserFile（attach）发出。
- 豆包输入框限约 2000 字：每份连同规格要**远低于** 2000 字（800–1300 字最稳），按章节拆，一份 1.5–2 分钟（台词 350–600 字），拆在段落转折处。
- 台词**一行一个意群**：换行 = 短停（0.2–0.3 秒），空行 = 稍长停（0.4–0.6 秒）。要砸下去的句子单独成行、前后空行，写进本份「留白」。
- **数字一律写汉字读法**：二零二六年、十一月二十三日、百分之三十一点五、一千二百万美元。字幕里照样用阿拉伯数字。
- **英文改成念得出来的中文**：CEO → 首席执行官；不好念的公司名改成描述（Megaspeed → 新加坡一家科技公司）；GPU 耶稣 → 显卡耶稣。字幕仍写原文。
- **接原声的地方，旁白只说引子，不念原话**，在「本份声音设计」里写：原声：「……」之后停 1 秒收住，成片在这里插入原声，**不要念原话**。
- 当事人原话（如“我昨晚干得不错吧？”）用旁白的口吻带出来，写明“不要模仿某某的腔调”。
- 台词和定稿逐字一致；为了好念改的字词，全部列在文末「交付说明」里。

## 模板

第 1 份写完整的音色、收音、混音；第 2 份起写「同第 1 份，同一克隆音色，不要换声」。

# 《片名》声音脚本 · 第 1/N 份 · 章节名

豆包输入框限约 2000 字。本份含规格与台词，请整份粘贴。
台词已断句。约 X 分 X 秒。
**只朗读「旁白台词」。** 换行短停；空行稍长停。

## 音色（时政底 · 自媒体口播感）

目标：时政热点，但像正常严肃的自媒体口播，跟人讲清楚一件事，不是播音员，也不是带货腔。
声线：成年男声，中低音略松一点；比纪录片多一点谈话感，仍克制。
语速：中速偏快，大约每分钟 260–280 字；数字咬清。
语气：像对镜头说话，句尾自然，可以有很轻的强调和一点点玩味；不要喊、不要笑、不要上扬的卖货尾音。
禁用：播音拖腔、网红撒娇、过度气声、假声。

## 收音

单声道旁白；48 kHz。干声、无回声、无底噪。峰值约 −6 到 −3 dBFS，不要削波。
换行停约 0.2–0.3 秒；空行约 0.4–0.6 秒；段末可到 0.8 秒。旁白轨里不要混进音乐。

## 混音

旁白主轨；配乐垫底，旁白出来时让开。成片约 −14 LUFS，真峰值 ≤ −1 dBTP。

## 本份声音设计

配乐：……
表演：……（哪句咬清、哪句压低、哪里停半拍）
原声：（有才写）「……」之后停 1 秒收住，成片在这里插入原声，**不要念原话**。
读音：（多音字）……
留白：「……」「……」

## 发出前自检

```sh
python3 scripts/check_doubao.py <片名>_豆包配音脚本_v1.md
```
每份 < 1900 字（最好 ≤ 1300）；台词里没有阿拉伯数字、英文字母、%。

## 交付时跟用户说什么

一共几份、每份多少字和大约多长、改了哪些字词；然后说清楚**下一步要用户做的事**：

> 请按份粘贴进豆包录音，**每份导出一个音频文件**发回给我（文件名带份号，比如 `第1份.mp3`）。录的时候念得和稿子不一样也没关系，以配音为准。
> 你录音的同时，我去开 PR 让 Grokbot 找素材。

## 音频回来以后

1. 存到 `demos/<项目>/配音/v1/narrator_part1.mp3 …`。**配音是用户的克隆声音，不提交到公开仓库**（mp3 本来就在 .gitignore 里），只提交识别和对齐的 json。
2. 识别：`python3 scripts/asr_vo.py --out 配音/v1/asr.json --prompt "<人名、机构>" 配音/v1/narrator_part*.mp3`
3. 对齐：`python3 scripts/align_vo.py <配音脚本.md> 配音/v1/asr.json 配音/v1/lines_aligned.json`。看打印的差异：用户念得不一样是常事，**以配音为准**，字幕跟着配音改；真的漏了一句才请用户单独补录这一句。
4. 语速：对齐脚本会打印每份的字/分钟。低于约 250 就建议整体变速（《黄仁勋》两版音色都在 230 左右，1.2 倍后约 280，用户满意）：
   `python3 scripts/speed_vo.py --tempo 1.2 --src 配音/v1 --dst 配音/v1_x1.2`
   用户提 1.25 倍时，先说明 1.2 倍更自然、1.25 开始发赶，再按用户的决定做。
5. 换音色（用户重录了一版）：新建 `配音/v2/`，从第 2 步重跑；画面时间线自动跟着新的逐句时间走，不用重新设计镜头。
