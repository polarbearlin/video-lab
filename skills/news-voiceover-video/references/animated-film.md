# 精细动画版：叙事插画图生视频 + 网页组件引擎（《Anthropic》v4 起的默认做法）

《Anthropic 上市四天破发》v4 照对标视频（“脑袋开瓶器 Brain Opener”那种）重做后沉淀下来。和 v1–v3 的做法（Pillow 逐帧、静态插画慢推，见 `production.md`，已另存为 `news-voiceover-basic` 无动画版 skill）相比，差别在三层：

| 层 | 无动画版 | 精细动画版 |
|---|---|---|
| 插画 | 10–12 张静态比喻图，不画人，慢推 | **每句一张的叙事插画**（可以画风格化真人），Grokbot 出图后**再做 5 秒图生视频**，一期 25–35 段 |
| 图表 / 文字 | Pillow 画的单页图 | **网页组件**（HTML/CSS/Canvas 逐帧截图）：纸片标签、盖章、画布镜头、文档荧光笔、动态图表、简历卡…… |
| 剪辑结构 | full.py 里手写镜头表 | **分镜表 storyboard.py** 一份表驱动底层视频轨和网页图层，逐镜头合成、有缓存 |

## 对标视频拆出来的“好在哪”（每期自查）

1. **画面一直在动**：对标片窗口里每分钟约 32 次明显变化（中位数 0.8 秒），但一个场景能停 5–10 秒——是“少切、多动”。我们 v4 量出来每分钟 15.5 次、中位数 3.3 秒，是最大的剩余差距。**目标每分钟 25 次以上，单个画面不超过 4 秒不变。**
   量法：`ffmpeg -i 成片.mp4 -vf "crop=1080:608:0:600,scale=720:405,select='gt(scene,0.18)',showinfo" -f null - 2>&1 | grep -c pts_time`，除以分钟数。
2. **插画在讲故事**：同一画风（构成主义海报：黑、琥珀、暗红、米黄，放射光束），每句旁白一个专门场景，主角是风格化的真人，镜头运动幅度大（穿过大楼、钞票雨）。
3. **信息图是一张大画布 + 虚拟镜头**：股权结构讲 90 秒，抠像头像贴在撕纸卡上、连线，镜头推拉摇移，讲到哪亮哪。
4. **文档有证据感**：纸页倾斜叠放，推到那一行，荧光笔扫过原句，中文翻译压在旁边。
5. **统一的视觉规范**：衬线（Display / 思源宋体）+ 无衬线混排，纸张做旧、颗粒、斜光网格底。
6. 清晰度不是原因（对标片只有 720p、24 帧）。

## 黄金 5 秒（用户原话：“要不立马开始说话，要不然原声内容要足够清晰”）

冷开场原声必须**第一句就点题**：v4 用“Anthropic raised the largest IPO offering on record”（福克斯）接“Shares fell below their $83 IPO price”（彭博），6 秒一个反差讲完。不要用“Also under pressure this morning…”这种需要上下文的句子。挑原声时把候选片段逐词识别，从主语开始剪。画面数量不用多（5 个镜头够），跟着声音走即可。

## 流程

1. **定稿、配音、对齐**：和原流程一样（`script.md`、`doubao-voice.md`）。时间线仍由 `film/full.py` 算（配音切份、BITES 原声表、字幕、混音），精细版只换画面。
2. **写分镜表** `film4/storyboard.py`（模板在 `assets/film4/`）：每条 `(起句, 止句, 底层, 图层)`。
   - 底层：`('clip', 素材键, 入点)` 真实视频 / `('framed', 键, 入点)` 装进米黄纸框 / `('illus', 'Pxx')` 叙事插画视频 / `('ground',)` 纯底纹（图层不透明时）/ `('cold', 列表)` 冷开场。
   - 图层：组件名 + 参数，见下表。
   - 一般比例：叙事插画约 1/3，真实视频约 1/3，组件页约 1/3。原声段一律用原片画面（口型对上）。
3. **叙事插画任务单**给 Grokbot（模板 `assets/templates/叙事插画画风与规格.md`、样例 `叙事插画任务单_样例.md`）：先交 1 张样张（图 + 5 秒视频）确认画风，再分三批交。每个镜头只抽一次（图生视频占用户月度套餐用量）。
4. **组件自查**：`node shoot.mjs still <时刻…>` 每种组件截一张，拼成联系表看排版（数字被盖、文字出画、人像截进字幕条都是这一步抓到的）。
5. **渲染**：`python3 storyboard.py && python3 compose.py 4`。逐镜头：后台 `shoot.mjs batch` 截透明 PNG → 叠到底层视频 → 压成小段 → 删帧；全部完成后拼接、加颗粒和暗角、套竖屏外框、字幕和 v3 的混音。缓存键 = 镜头内容哈希，改哪个只重渲哪个；改了 index.html 会全部重渲。
6. **审片**：联系表 + 画面变化频率 + 响度（`qa-delivery.md`）。

## 组件（`assets/film4/index.html` 的 COMP）

| 组件 | 用途 | 参数要点 |
|---|---|---|
| `tag` | 米黄撕边纸片标签（左上 / 左下），带回弹 | `html`（`<span class="k">日期</span>`、`<b>红字</b>`）、`pos`、`small` |
| `quote` | 暗红条打字引语 | `text`、`src` |
| `counter` | 金色大数字滚动 + 说明条 | `value`、`unit`、`sub`、`fmt:'int'` |
| `title_ipo` | 片名：价格线跌穿发行价 + 盖章震动 | 改成本期的日期和价格 |
| `compare_cards` | 画布上两张照片卡，镜头横移、虚线连接、盖章、拉远 | `cards`、`first`、`stamp` |
| `price_overlay` / `price_full` | 插画上叠价格线 / 纸面 K 线跌破发行价 | 数据写在组件里 |
| `doc` | 文档纸页倾斜推近、荧光笔、中文贴条；可第二处高亮、可落照片 | `img`、`w`、`hl`/`hl2`（页面坐标）、`tr`/`tr2`、`photo`、`src` |
| `letters` | 字母逐个亮起（ANTHROPIC、P B C） | `text`、`sub`、`spread` |
| `stamp_only` / `headline` / `bigtext` / `chapter` | 盖章、大标题、大字、章节卡 | — |
| `bars` / `loss` / `calendar` | 纸面柱状、亏损拆非现金、21 格对 4 格日历 | — |
| `resume` / `duo` | Resume. 简历卡、两人对比卡 | 头像要裁掉新闻台字条 |
| `speedo` | 车速表（比方） | — |
| `twocol` / `three` / `twoword` | ✓✗双栏、三个猜测卡、两词对比 | `at`（某句开始时出现，用 `at_key`） |
| `end` | 片尾署名 + 评论区提问 | 署名写这一版真正用的素材和配乐 |

全局：每个切点一闪琥珀漏光；颗粒和暗角在 ffmpeg 里统一加（不要在网页里加，否则透明 PNG 太大）。

## 下一步要补的（v4 之后的已知差距，按收益排）

1. **画面密度**：超过 4 秒的镜头拆成 2–3 个画面；组件里每秒一个小节拍。
2. **大画布讲解段**：20–30 秒，抠像头像 + 撕纸卡 + 连线 + 镜头移动（人物关系、股权、资金流向）。
3. **转场**：推进穿越、横扫、纸片翻页（可以用网页图层在切点上画，不改时间线）。
4. 动作偏小的图生视频重抽；超过 5 秒的插画镜头用第二张插画，而不是放慢。

## 踩过的坑

- **Grokbot 交来的图生视频带封面小图**（第二路视频流 attached_pic）：`-map 0:v` 会把它也当视频，报 “Could not find tag for codec h264 in stream #1”。一律 `-map 0:v:0`。
- 图生视频只有 5 秒：镜头更长时，放慢不超过 2 倍；视频后段崩坏（人物突变）就只用前一段，接那一帧的定格慢推（`{'src_max': 1.4}`）。
- 全片透明 PNG 一次性截完要几十 GB：必须逐镜头截、合成、删帧。
- 浏览器截帧和 x264 是瓶颈：云端 4 核整片约 40 分钟；用户的 M2 Max 本地渲染预计快 3–4 倍（可让 Grokbot 在用户 Mac 上跑，或远程控制）。加颗粒那一步会生成 1.7 GB 中间文件，可以和套外框合成一遍。
- 改冷开场原声的时长会让后面所有镜头时间变化，网页图层要整片重渲；能等长替换就等长替换。
- 手动停掉的渲染会留下截了一半的帧目录，重渲前删掉 `tmp/` 里的旧目录。
- 中间产物都放在 `VL_OUT`（不进仓库）；`film4/.gitignore` 忽略 `fonts/`、`out/`。
