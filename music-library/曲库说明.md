# 配乐曲库（时事新闻口播片可重复使用）

## 怎么取用

```sh
git fetch origin news-voiceover-kit
git checkout origin/news-voiceover-kit -- music-library      # 取到当前分支的工作区
cp music-library/suno/* demos/<项目>/素材/audio/suno/          # 渲染管线默认从这里读
bash music-library/fetch_mixkit.sh demos/<项目>/素材/audio     # 需要 Mixkit 曲子和音效时
```
新曲子入库：`python3 <skill>/scripts/music_bars.py 新曲.mp3 --bpm <速度> --name <名字> --json music-library/suno/bars.json`，
mp3 用 `git add -f`（仓库默认忽略 mp3），再在下面补一行说明。
仓库是公开的：这里只放用户同意公开的 Suno 曲子；用户的配音不放；Mixkit 不允许单独再分发，只放下载脚本。

## Suno 曲子

两首是同一条提示词（`JH_full_score`，见 skill 的 `assets/example/黄仁勋_Suno单曲提示词.md`）生成的两版：
100 BPM 左右（实测 99.4）、D 小调，一小节 2.392 秒，两首拍速一致，可以混着剪。纯音乐，没有人声。
用于《黄仁勋复职的十一天》修订 v3（2026-11），由用户用 Suno 生成并同意入库。商用发布请确认生成时是付费账号。

### suno_a.mp3（162.4 秒，第一条小节线 0.16 秒）

| 时间（秒） | 情绪 | 黄仁勋片里用在 |
|---|---|---|
| 0.2–19.4 | 轻、稀疏的开场，低频弱 | 起因段开头（调查感） |
| 19.4–67.4 | 鼓进来，逐步推进，中等能量 | 起因段 |
| 67.4–77.0 | 能量上来 | 白宫段开头 |
| 77.0–86.6 | 几乎没鼓（打击乐 0.07），冷 | 质疑段 |
| 86.6–134.6 | 持续推进、最满的一段 | 白宫段（政治惊悚感） |
| 134.6–162.4 | 收尾，自然结束 | 结尾（对齐片尾） |

### suno_b.mp3（177.0 秒，第一条小节线 19.37 秒）

| 时间（秒） | 情绪 | 黄仁勋片里用在 |
|---|---|---|
| 0–19.4 | 无鼓前奏，稀疏 | 质疑段 |
| 19.4–57.8 | 最亮、打击乐最密（放克感） | 狂欢 / 玩梗段 |
| 57.8–67.3 | 突然变空（打击乐 0.08） | 质疑段 |
| 67.3–105.7 | 暗色、满编、低频重 | 钩子 |
| 105.7–125.0 | 沉稳、有压力 | 辞职被拒段 |
| 125.0–134.6 | 安静一段（响度 −19.9） | 可做停顿 / 转场 |
| 134.6–177.0 | 收尾，最后几小节很暗 | 结尾 |

`bars.json`：每首的小节线（`bars`）和每 4 小节的响度 / 低频 / 亮度 / 打击乐比例（`blocks`），剪的时候切点吸附到小节线。
