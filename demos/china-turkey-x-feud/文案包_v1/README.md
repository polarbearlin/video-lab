**一句话：只差你确认文案；确认后我再出配音脚本和画面。另有一条土耳其媒体引语是中文转述，出片当天可再核。**

出片当天需要复核的 5 件事：

3. **两国官方是否表态**：截至 11月8日，公开报道里没有；出片当天再查一次。
4. **X 原帖是否还在**：原账号疑似删除，截图已传开；如果原帖恢复/账号复活，角标要改。
5. **E11 土耳其媒体引语**：目前依据是 woshipm 对 Sözcü/Mynet/Ensonhaber/Türkgün 的中文转述，没有直接打开 Türkgün 原文；出片当天可再核，或把“一家土耳其媒体专门补了一句”改成“有报道说”。

## 没有用的说法（已排除）

- “土耳其政府要求马斯克封禁中国账号”——只有论坛/自媒体标题，无主流媒体报道；未用。
- “索南”——身份和原始发言未确认；未用。
- “所有土耳其网友都破防/都骂不过”——以偏概全；正文用“一些账号”“土耳其一方”。
- “中国网友完胜/土耳其惨败”——主观夸大；正文用“场面上的声量……占了上风”。
- “土耳其国旗真是派大星设计的”——是梗；正文明确是玩笑。
- “土耳其把新疆写进教材版图”——只有中国自媒体解读；正文用“中国自媒体批评”限定。
