# 《海上年画 · 英雄谱》设计说明（风格卡）

一次"年画风格"探索：把《海贼王》里令人印象深刻的配角，画成中国木版年画。

## 1. 风格卡（这次我自己补足的规则）

| 项 | 规则 | 为什么 |
|---|---|---|
| 参考 | 杨柳青年画（细腻、人物喜庆）+ 桃花坞年画（色块大胆） | 年画里最有辨识度的两派 |
| 颜色 | 大红 #D7261E、桃红 #F06C9B、明黄 #F7C21B、金 #E0A526、翠绿 #1E9E5A、靛蓝 #1F4E9C、天青 #3FA7D6、紫 #7B3F98；底色宣纸 #F4E6C8 | 年画是"品色"平涂，不用渐变 |
| 线条 | 粗黑墨线勾边，线头圆润 | 木版的墨线版 |
| 套色错位 | 颜色版整体偏 4×3 像素再印墨线 | 木版套色印刷对不准的手工味，一眼"不是电脑画的" |
| 构图 | 人物居中对称，门神站姿；上横批，右上联，左下联 | 年画、春联的标准格式 |
| 纹样 | 海水江崖纹（海浪 + 立水斜纹 + 山石）、祥云、回纹边框、铜钱、背光圈 | 海水江崖纹本来就画海，正好配"海贼" |
| 人物 | 大头小身（头 : 身 ≈ 1 : 2.5）、圆脸红脸蛋；只保留每个角色的标志性特征 | 年画"胖娃娃"的比例；特征让人认得出，又不照搬原画 |
| 字 | 对联、横批用马善政毛笔体；名牌用文楷 | 春联的毛笔感 + 说明文字好读 |
| 质感 | 宣纸斑点和纤维 + 套色颗粒 | 印在纸上的感觉 |
| 落款 | 每张一方朱文印章（角色称号） | 年画、书画的落款习惯，也是"系列编号" |

## 2. 角色怎么"认得出来"：只抓标志特征

| 角色 | 标志特征 |
|---|---|
| 白胡子 | 白色新月胡子、黑头巾、白披风、薙刀 |
| 艾斯 | 橙色牛仔帽 + 笑脸 / 哭脸徽章、雀斑、红珠项链、火拳 |
| 香克斯 | 红发、左眼三道疤、黑披风、空荡荡的左袖、酒碗 |
| 罗 | 白底黑斑毛绒帽、山羊胡、耳环、黄黑卫衣、长刀、蓝色 ROOM |
| 卡普 | 白发白胡子、海军帽、"正义"大衣、铁拳、甜甜圈 |
| 汉库克 | 黑长直、齐刘海、牡丹长裙、白蛇萨洛美、爱心 |

## 3. 文案：每人一副对联（三轮独立评审）
- 横批 ≤ 4 字（称号或梗），上下联各 7 字。
- 上联末字仄声、下联末字平声；词性结构大体对应。
- 每张只停约 4 秒：下联尽量出现观众熟悉的名字（柯拉松、路飞），没看过原作也能读到情绪。
- 开场、结尾用吉祥话收住，结尾带互动钩子。

评审过程和定稿见 `copy.md`。

## 4. 30 秒怎么动（关键帧之后的动画计划）
- 开场 3 秒：红纸"啪"地展开，横批先印出来，对联从上往下逐字印上（像盖章）。
- 每位角色约 4 秒，共 6 位：
  - 先印颜色版（色块错位着出现），0.3 秒后墨线版"压"上去，画面一下清晰；
  - 角色的小动作：披风飘、火焰跳、空袖子晃、ROOM 圈呼吸、铁拳出拳、爱心往上飘；
  - 最后印章"咚"地盖下去，切下一张。
- 结尾 3 秒：六个团花圆框依次亮起，海船扬帆，横批"扬帆大吉"。
- 转场：像翻年画册，红纸从右往左翻页。
