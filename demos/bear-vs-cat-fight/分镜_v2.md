# 《北极熊 vs 大馋猫》v2 分镜（招式版）

时间表的唯一来源：`src/timeline.py`。画面读它（`scene2.py`），声音也读它（`audio2.py`）。

**节奏**：开场 → 第一轮连击（瞬影 + 三连斩 + 上勾拳挑飞）→ 霜龙斩（镜头切入）→ 空中连斩 → 地裂 → 鱼海漩涡（镜头切入）→ 中场对撞 → 鱼骨三连 / 瞬影闪避 / 爱心鱼雷 → 空中对撞 → 月牙斩（镜头切入）→ K.O. → 胜利镜头 → 大馋猫探头。

**招式（原创名字）**
- 北极熊
  - 踏冰·瞬影：冲刺，留冰蓝色残影。
  - 三连斩 + 上勾拳：挑起对手。
  - 霜龙斩：蓄力时地上冒冰刺，镜头切入特写，然后放出冰龙。
  - 空中连斩 + 地裂：跳起三斩，落地裂开冰面。
  - 月牙斩：镜头切入，大弧形冰刃。
- 大馋猫（娇滴滴的小姑娘）
  - 三连鱼骨弹：快速扔三根。
  - 猫步闪避：粉色残影。
  - 爱心鱼雷：一串爱心 + 小鱼。
  - 鱼海漩涡：鼓腮蓄力，鱼绕嘴转，镜头切入特写，然后喷向熊。

**镜头语言**
- 镜头切入（cut-in）：战斗中定格，取景角色特写，斜向放射速度线，大字招式名。
- 命中停顿：每次命中停顿 0.06–0.30 秒，姿势冻结，闪白只闪 0.07 秒。
- 反色闪：重击那一帧整屏反色。
- 推近：重击瞬间镜头推近 8–16%。
- 震屏：重击时画面抖 2 像素。
- 台词气泡：熊和猫各有几句台词（见 `timeline.py` 的 `BUBBLES`）。

**声音**：拔剑、冲刺、拳击、挡剑、冰龙咆哮、镜头切入的低频推进、鱼海咕噜、爱心弹跳、地裂重击、胜利音乐。整片 −14 LUFS，峰值 −1.3 dB。
