# 《黄仁勋复职的十一天》Suno 定制配乐提示词 v1

用途：替换修订 v2 里的 Mixkit 曲库配乐。一共 7 段，每段一条提示词，按段落情绪写好了。
你在 Suno 生成，把满意的版本发给我；我负责剪到画面长度、对齐鼓点、做停乐、上升音和混音。

## 怎么用（每一段都一样）

1. Suno 选 **Custom（自定义）** 模式，模型用最新版。
2. 打开 **Instrumental（纯音乐）**。
3. 把下面的 **Title（标题）**、**Style（风格）**、**Exclude Styles（排除风格）** 分别粘进对应的框，不填歌词。
4. 每次生成会出 2 个版本。按每段的「试听标准」挑一个，不满意就再生成一次。
5. 下载 **mp3（有 wav 更好）**，文件名用标题，比如 `JH01_hook.mp3`，直接发到这个对话里。

几点说明：
- 每首生成 1 分半到 3 分钟都可以，比需要的长没关系，我会挑最好的一段来剪。
- 7 首都在 D 小调这一组（狂欢段用它的关系大调 F 大调），换段更顺。
- 用来发布的话，生成时请用 Suno 的付费账号，免费账号生成的音乐不能商用。

## 01 钩子 · 0:05–0:38（约 33 秒）

画面：琼斯说“不打算让他复职”→ 全票复职 → 股价暴涨 → “我昨晚干得不错吧？”→ 11 天。要一开场就抓人。

**Title：** `JH01_hook`

**Style：**
```
dark cinematic trap news beat, 96 BPM, D minor, hard-hitting 808 sub bass, crisp rolling hi-hats, punchy snare, sparse dark piano stabs, tense string swell, glitchy stutter fills, big cinematic boom on the downbeat, drums start from the first bar, short intro under 2 bars, steady loopable 8-bar groove, sparse midrange that leaves space for voice-over, modern documentary YouTube style, clean punchy mix
```

**Exclude Styles：**
```
vocals, vocal chops, choir, rap, spoken word, shouts, guitar solo, lo-fi vinyl crackle, happy, cheerful
```

**试听标准：** 第一小节就有鼓和 808；不吵人声频段（钢琴和弦稀疏）；整首速度稳定、不突然变奏。
