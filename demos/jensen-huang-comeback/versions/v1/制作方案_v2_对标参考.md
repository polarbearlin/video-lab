## 二、我们怎么做

### 1. 版式：一套时间线，出两个版本
- **竖屏 1080×1920（对标参考，主推抖音）**：顶部两行标题固定（例：「黄仁勋 11 天被请回」／「特朗普一通电话，董事会为何全票反转？」），中间 16:9 画面窗，窗下字幕，底部频道名。
- **横屏 1920×1080**：同一条画面窗时间线放满屏，字幕压在底部。
- 频道名和标志**不用参考视频的**，用你自己的（需要你给名字或 logo）。

### 2. 主色
黑底 + 英伟达绿（#76B900）做主强调，红色只用在“质疑、风险、调查”上，白字。和参考一样全片统一调色，但颜色贴合英伟达题材，不照搬他们的橙红。

### 3. 画面四层（约 80–90 个镜头，平均 3–4 秒一切，钩子段 1.5–2 秒一切）

| 层 | 占比 | 内容 | 来源（交 Grok Bot） |
|---|---|---|---|
| 真实视频 | 约 45% | 黄仁勋 GTC / Computex 演讲、白宫活动（10/8 颁奖、9/24 国宴到场）、国会和委员会画面、纳斯达克 / 华尔街 / 硅谷总部 / 数据中心 / 新加坡空镜 | 英伟达官方 YouTube、白宫官方视频（美国政府作品）、国会委员会官方直播、免费商用素材站（Pexels / Pixabay）；新闻台片段只取短引用（每段 ≤5 秒）并标来源——用不用由你定 |
| 文件拼贴动画 | 约 30% | 英伟达两份公告、8-K、时报 / 华尔街日报标题、全员信、外交部实录、实体清单、马斯克 / Calacanis 原帖、特朗普 Truth Social、议员声明 | 真实网页截图（v1 任务单里的 J 项大多保留），我用代码做撕纸、推近、高亮划线 |
| 数据图 | 约 10% | 11 天时间轴、日涨跌幅柱（11/23 一根 +31.5% 的大柱）、英伟达 vs 纳指、请愿计数器、持股数字 | 官方行情 CSV（J1），代码绘制 |
| 插画 | 约 15% | 参考用的是 AI 油画风插画。我们题材涉及真人和婚外情、间谍指控，**只做不出现真人面孔的示意图**：深夜会议室、空着的 CEO 座椅、电话、棋盘、芯片走私路线、国会听证席位等 | 即梦生图（花积分，先报价等你确认）；或者不用插画，全部用真实视频 + 拼贴 |

### 4. 声音
- **冷开场**：先放 3–5 秒英文新闻原声（新闻台播报“英伟达董事会恢复黄仁勋 CEO 职务”），配五六个快切，再进你的旁白第一句。旁白不用重录。
- 配乐：低频紧张感的垫乐，转折处收；音效：快门、翻纸、键盘、股价跳动的“嘀”声。配乐找免费可商用曲目（Grok Bot）或代码合成。
- 你的豆包配音是主轨，按它的实际时长排每一个镜头。

### 5. 流程
1. **你确认本方案**（下面四个问题）。
2. 我出**素材任务单 v2**：逐镜头列出要什么视频、从哪找、截哪几秒、分辨率、授权、找不到的替代。发到 PR 给 Grok Bot。
3. 你的配音到了 → 我用语音识别切出每句的时间 → 出**逐镜头分镜表**（每个镜头的起止时间、画面、素材编号）。
4. 素材到了 → 代码合成（Python + ffmpeg 做剪辑和外框，文件拼贴和数据图逐帧生成）→ 出低清初版。
5. 开一个独立的审片代理，按参考视频逐项打分（节奏、画面密度、字幕、来源标注、有没有违规素材），不到标准就改。
6. 出竖屏和横屏两个成片，交给你。

### 6. 底线（不变）
- 不用红胸罩改图；不出现当事女高管的照片；不提第二段关系对象。
- 不用 AI 生成真人面孔；示意插画标“示意”，不冒充实拍。
- 每个事实画面都有来源角标。

## 三、需要你定的四件事

1. **竖屏还是横屏为主？** 我建议两版都出，竖屏对标参考。
2. **频道名 / 标志**：底部品牌区写什么？
3. **新闻台视频片段**（CNBC、ABC 等的播报画面）能不能用短引用？参考视频用了 CNN。我建议可以，每段 ≤5 秒并标来源；不行就只用官方和免费素材。
4. **示意插画要不要用即梦生成？** 约 10–12 张、不出现真人面孔，我先查报价再等你确认；不要的话就全部用真实视频和拼贴。
