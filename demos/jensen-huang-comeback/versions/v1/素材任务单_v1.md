# 素材任务单 v1 · 黄仁勋复职的十一天（交给 Grok Bot）

对应定稿文案：`versions/v1/自媒体文案_v2_定稿.md`。配音由 Vasanti 录制中。
画面：横版 16:9，1920×1080。版式是“案卷 + 数据”：黑 / 夜蓝 / 报纸三种底色，真实截图做卡片，K 线和时间线用代码画。

## 交付方式

- 放进同一分支 `collab/jensen-huang-comeback`，目录 `demos/jensen-huang-comeback/素材/`：
  - 图片：`素材/img/`（PNG）
  - 数据：`素材/data/`（CSV）
  - 视频：`素材/video/`（mp4；根目录忽略 `*.mp4`，提交时用 `git add -f`；单个超过 50 MB 就放草稿 Release）
- 每个文件在 `素材/来源表.md` 登记一行：
  `| 文件名 | 编号 | 内容 | 来源 URL | 发布/更新时间 | 截图时间 | 授权说明 | 备注 |`
- 截图规格：浏览器视窗 1920×1080（或 1280×900），PNG，页面原样，不改字。标题、媒体名、日期要在图里能看到；关键句可以另存一张局部裁图（文件名加 `_crop`）。
- 每批交付后在 PR 留言：`【交付】J1 J2 …；新增图片 N 张；来源表已更新`。找不到的写“未找到”和原因，不要用别的东西冒充。

## 不要收的

- 特朗普转发的红胸罩改图（只在旁白里不出现，画面也不用）。
- 当事女高管（Alice Huang）的任何照片；第二段关系对象的任何信息。
- 路透 / Getty / AP / 法新社的新闻照片和视频画面（版权）。
- AI 图、AI 视频、梗图里的真人形象当作实拍使用。
- 普通网民的头像和账号：按你们原有规则处理（打码或只用正文）。
