# 任务：爱泼斯坦案时政口播视频（先出文案）

你要帮我做一条中文时政自媒体视频，题材是爱泼斯坦案的最新进展。**这一步只出文案**，文案经我确认以后，再出配音脚本、做画面。

请先完整读一遍我给你的视频 skill（code-video-studio）。这类片子对应的文件是：
- `references/news-explainer.md`：时政/实证新闻的完整流程、我的风格偏好、踩过的坑。
- `assets/script-rubric.md`：文案评分表和独立评审提示词。
- `references/documentary.md`：素材授权、事实表的写法。
- 样例：`assets/example-news-breakdown.md`、`example-news-script.md`、`example-news-facts.md`。

skill 里的规则和这份提示词有冲突时，以这份提示词为准。

---

## 一、我是谁、要什么

- 我是中文自媒体创作者，做时政解读。平台是视频号、抖音、B 站，观众是中国大陆的普通人。
- 我要的片子：**爆点密、钩子强、让人愿意看完，而且每句话都经得起评论区挑错。**
- 对标标题（同题材的爆款，只有标题）："爱泼斯坦案最新嫌疑人引发全球震动，遗作炸裂内幕独家公开！#弗吉尼亚朱弗雷 #美国 #爱泼斯坦"
  - 学它：关键词前置；"最新嫌疑人""遗作"的悬念感。
  - 不学它："独家""炸裂内幕"之类的夸大说法，以及把未被起诉的人说成"嫌疑人"的暗示。
- 题材范围：
  - 弗吉尼亚·朱弗雷的遗作回忆录；
  - 安德鲁被捕（以及他涉嫌的到底是什么）；
  - 美国司法部公开爱泼斯坦文件之后，英美两边的不同结果；
  - 文件里观众熟悉的名字；
  - 最新进展，以及"为什么现在看"。
  - 你自己查资料，可以挖得深一点，但要以今天的日期为准。

## 二、流程（按顺序，不要跳步）

1. **拆对标**：用标题的写法和 skill 里的对标拆解样例，写下钩子打算怎么做、要学什么、不学什么。
2. **找料，进事实表**：
   - 来源分三层：官方原始数据和文件、主流媒体的一手报道、二手转述。二手转述只当线索，必须追到原文。
   - **搜索摘要不算核实。** 每一条事实都要打开原文，原句摘进 `FACTS.md`（编号、片中说法、来源链接、英文或中文原句），页面存一份到 `raw/`。
   - 会变化的事实（有没有被起诉、有没有新文件、有没有减刑）要写清楚"截至某日"，出片当天再查一次。
   - 云端提示：维基百科 API 常被限流，部分网站会 403。打不开就换来源或用网页读取工具，不要用摘要顶替。
3. **写稿**：结构和写法见下面第三节。稿子里每句话都要标〔E#〕（事实编号）、〔判断〕（观点）、〔角标：…〕（画面出处，旁白不念）。另外出一份纯净版给我看。
4. **独立评审**：
   - 起一个没参与写作的子代理，用 `assets/script-rubric.md` 的评分表 v2 打分：门槛 + 7 项 + 每 30 秒一格的留存地图。
   - 90 分以上才交给我，最多 3 轮。
   - 评审建议加的新料，你要自己打开原文核实过才能用。
   - 我对 token 消耗敏感：评审时优先用本地存档核对，网络抽查每轮不超过 3–6 条。
5. **交给我确认**：
   - 文案纯净版、带标注版、事实表、评审记录；
   - 写清楚：有哪些改动没有再送审；哪些事实需要出片当天复核。
   - **没有我的确认，不出配音脚本，不做画面。**

## 三、写法要求（这些是我反复调过之后定下来的，务必遵守）

**结构**
- **钩子不超过 25 秒**：前 3 秒要有一个具体、反常的事实；15 秒内说清"讲什么、为什么现在看"；最后留一个问题。
- **钩子之后，第一段直接讲事件本身**，背景放到后面。
- **"一层一层剥"**：每层一个问题、一个答案。
- 每段不超过 45 秒，大约每 20–30 秒给一个新爆点、新反转或新悬念。
- **结尾不超过 20 秒**：先用一句话回答开头的问题，再回扣全片一个记忆点，最后落在下一个检验点上，引导关注。要巧，不要官方腔。

**时长**
- 视频号/B 站版：3.5–5 分钟。
- 抖音版：另写一个 1.5–2 分钟的版本，不要从长版硬砍。
- 字数按每分钟 280 字估算。

**爆点和原话**
- **爆点当骨架，原话只用来点睛**：全片留 4–5 句最有分量的当事人原话就够了，不要每段都塞原话，会显得刻意。
- "据某某报道"之类的出处挪到画面角标，旁白里只保留"似乎显示""她说""据她回忆录"这类必要的限定词。
- 观众认识的名字（特朗普、马斯克、克林顿等）要出现，但必须遵守下面的门槛。不认识的名字一笔带过，不要连着念。

**语气**
- 口语，短句，句子不超过 42 字，有设问。
- **不说教**：不要单列一段"这跟你有什么关系 / 家长要警惕 / 别急着转发"。第二人称用一句话自然带过就行。
- **旁白不念心理援助热线。** 热线放不放在画面小字里，由我决定。

## 四、门槛（任何一条不过，分数再高也不能交）

- 指控只能写成指控：写明是谁说的，对方的否认紧挨着写。被提到不等于犯罪。
- 不暗示任何未被起诉、或者已经否认的人有罪。**标题和钩子也算。** 例如不能把"他否认了某项指控"和"后来他因为别的事被捕"并列，那样听起来就是"他撒了谎"。
- 不诱导观众猜测未具名的人。例如回忆录里没写名字的"首相"：不提，不给线索。
- 不暗示存在一份藏起来的名单；不写"两件事有没有关系，我们不猜"这类欲盖弥彰的话。
- 涉及自杀，不写方式和细节；涉及未成年人，不写任何性细节；不出现性犯罪报案人的任何信息（英国法律规定报案人终身匿名）。
- 不用"独家""炸裂"等夸大说法；时间锚要准确，比如"到今年四月初"，不要把旧数据当成现在的结论。

## 五、交付物（这一步只交文案）

1. `FACTS.md`：事实表，每条都有原文；末尾列出"不用的说法"。
2. `SCRIPT_vN.md`：带标注的文案，视频号/B 站版和抖音版各一份。
3. 纯净版文案：方便我直接读。
4. 评审记录：每一轮的分数表、留存地图，以及每轮改了什么。
5. 一句话说明：现在离可以出片还差什么，比如哪些事实需要出片当天复核。

文件要放在我能打开的工作目录里。如果有 GitHub 仓库，推到一个新分支，不要动 main。
