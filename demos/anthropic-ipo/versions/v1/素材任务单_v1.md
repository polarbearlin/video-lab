## 一、交付规格

- 视频：mp4，**1080p 优先，最低 720p**，保留原声。截取需要的段落，前后各多留 2 秒。超过 50 MB 的放草稿 Release，其他放 `demos/anthropic-ipo/素材/video/`（`git add -f`）。
- 截图：PNG，整页一张 + 关键段落裁切一张（`J06_guardian_protest.png` / `J06_guardian_protest_crop.png`），字要在手机上看得清。X 原帖里普通网友的头像和名字打码。
- 数据：CSV（日期、开、高、低、收、成交量），**等美东 16:00 收盘后再取**。
- 文件名：编号开头，`V10_cnbc_falls_below_ipo.mp4` 这种。
- 每个文件在 `素材/来源表.md` 登记一行：`| 文件名 | 编号 | 内容 | 来源 URL | 原片起止 | 发布日期 | 分辨率 | 授权/引用说明 | 备注（相似替代）|`
- 每批推送后在 PR 留言：`【交付】V01 V02 …；视频 N 段，截图 N 张；来源表已更新`。找不到写“未找到 + 原因”。
